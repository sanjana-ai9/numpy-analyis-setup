# NumPy Statistical Analysis

## Description

This project demonstrates basic statistical analysis using NumPy in Python. I created a numerical dataset containing student marks and calculated different statistical measures.

## Objective

To understand how NumPy helps perform statistical calculations on numerical data.

## Tools Used

* Python
* NumPy
* Jupyter Notebook

## Operations Performed

1. Created a NumPy array containing student marks.
2. Calculated the mean (average).
3. Calculated the median.
4. Calculated the standard deviation.
5. Found the minimum value.
6. Found the maximum value.

## Dataset

Student Marks: [75, 80, 85, 90, 95]

## Results

* Mean: 85.0
* Median: 85.0
* Standard Deviation: Approximately 7.07
* Minimum Marks: 75
* Maximum Marks: 95

## Learning Outcome

Through this task, I learned how to use NumPy functions to calculate statistical measures and understand numerical data more effectively.
